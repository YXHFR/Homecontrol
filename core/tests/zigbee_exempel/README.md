# Exempelmeddelanden från Zigbee2MQTT

Meddelanden i samma form som Zigbee2MQTT 2.x skickar dem på MQTT, för
kopplingstesterna i `test_zigbee.py`. Varje fil har en beskrivning och
meddelandena i den ordning de kommer.

IEEE-adresserna är påhittade, och filerna innehåller inga nätverksuppgifter
(inga `bridge/info`, nycklar, adresser eller kanaler). Spelas nya meddelanden
in från ett riktigt Zigbee-nät ska adresserna bytas mot påhittade först.
